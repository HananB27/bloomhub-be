# Gardener Domain

## Domain

- Gardener should keep changes within this project's domain. Flag work that introduces features outside it.
- In-domain: `web-backend`.
- In-domain: `ai/llm`.
- Capability: Django REST API.
- Capability: JWT authentication.
- Capability: CORS handling.
- Capability: LLM integration (via LangChain).
- Capability: SQLite/PostgreSQL database support.

## Out-of-Domain Examples

- mobile app functionality
- desktop application features
- frontend UI development
- non-web backends (e.g., CLI tools, background job processors without web interface)
